DESCRIPTION:

This repository includes the HTML, CSS, and JavaScript front-end design for a multi-page e-learning platform. The user interface offers a fun and easy way to browse courses, view progress, and access learning resources like embedded videos. It mimics the appearance and feel of a contemporary online learning platform.

Clean layout, responsive design, and easy navigation are key components of the platform's design, which mimics real-world learning environments.

Project Goal

To use front-end web technologies to develop an aesthetically pleasing and interactive multi-page user interface for an e-learning platform that incorporates progress tracking, video playback, and course browsing.

Technologies Used 

HTML: Offers the framework for all pages, including forms, content sections, headers, and footers.

CSS: Uses either conventional CSS or utility-first frameworks like Tailwind to style the layout with a simple, responsive, and contemporary design.

JavaScript: Provides interactive features like form validations, dynamic user interface elements (tabs, modals), progress tracking, and video embedding.

Qualities
Home, Courses, Course Details, and User Progress Dashboard are all included in the multi-page layout.

Course Listing: Enrollment options, descriptions, and thumbnails are displayed for each course.

Video Embedding: Allows video lessons to be embedded into the course detail pages, either locally hosted or on YouTube.

Progress Tracking User Interface: Users can view visual cues about their course completion status, such as progress bars.

Responsive Design: Completely compatible with tablets, smartphones, and PCs.

Interactive Features: The user experience is improved by modals, navigation menus, collapsible sections, and hover effects.
